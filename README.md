# MLOps 

## Overview
This repository contains my implementation of a comprehensive MLOps curriculum. It serves as a practical showcase of my ability to build, deploy, and maintain production-ready machine learning systems. Through these projects, I have transitioned models from isolated development environments into robust, automated, and monitored pipelines using modern engineering best practices.

## What I Have Learned & Implemented

Here is a detailed breakdown of the skills I have mastered, organized by the project labs completed in this course:

1. **[MLOps introduction](lab1)** - Dependency management, enforcing code quality, Git workflows, building APIs with FastAPI, and containerization with Docker.
2. **[Databases & file formats](lab2)** - Managing relational data with PostgreSQL, using DuckDB, and working with Parquet file formats.
3. **[Data processing](lab3)** - High-performance data manipulation and processing using Polars.
4. **[Vector databases](lab4)** - Implementing semantic search using pgvectorscale, SQLAlchemy, and Milvus.
5. **[Versioning](lab5)** - Tracking experiments and versioning large datasets/models with DVC and MLFlow.
6. **[ML testing & data-centric AI](lab6)** - Applying data-centric AI principles, model testing, and explainability using CleanLab, Giskard, Captum, and SHAP.
7. **[Model optimization for inference](lab7)** - Accelerating model serving through PyTorch optimization, ONNX, and ONNX Runtime.
8. **[Monitoring & drift detection](lab8)** - Implementing data and concept drift detection and monitoring production performance with Evidently and NannyML.
9. **[Introduction to cloud computing](lab9)** - Working with AWS cloud services for machine learning workloads.
10. **[Infrastructure as Code (IaC)](lab10)** - Provisioning and managing cloud infrastructure programmatically using Terraform.
11. **[Deployment & CI/CD](lab11)** - Automating testing and deployment pipelines using GitHub Actions.
12. **[ML pipelines](lab12)** - Orchestrating complex machine learning workflows with Apache Airflow.
13. **[LLMOps](lab13)** - Serving Large Language Models with vLLM, implementing the Model Context Protocol (MCP), and setting up LLM guardrails.
14. **ML system design** - Architecting scalable and robust machine learning systems from end to end.
